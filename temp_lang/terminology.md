## Special Considerations

### Electrical Standards

- Follow IEC 60617 standard for electrical symbols
- Use standard electrical terminology
- Maintain consistency with industry standards

### Technical Accuracy

- Ensure electrical terms are technically correct
- Use proper electrical engineering terminology
- Maintain consistency across all translations

### User Experience

- Use clear, concise language
- Avoid technical jargon where possible
- Ensure UI text is user-friendly

### Code Consistency

- Maintain consistent naming conventions
- Use camelCase for variables and functions
- Use PascalCase for classes
- Use UPPER_CASE for constants

## Translation Guidelines

1. **Consistency**: Always use the same English term for the same French term
2. **Context**: Consider the context when translating ambiguous terms
3. **Technical Accuracy**: Ensure electrical terms are technically correct
4. **User-Friendly**: Use clear, understandable language
5. **Standards**: Follow electrical engineering standards and conventions
